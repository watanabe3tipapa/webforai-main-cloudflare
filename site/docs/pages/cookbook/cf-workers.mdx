# Cloudflare Worker をセルフホストする

webforai には、公開 URL または HTML を Markdown に変換する Cloudflare Worker 実装が含まれています。このレシピでは、現在の `/app/` Web-UI と `POST /api/convert` を自分の Cloudflare アカウントへ公開します。

> この Worker は `fetch` で取得できる公開コンテンツを対象にします。Cloudflare Browser Rendering、Durable Objects、Browser Rendering API の設定は必要ありません。JavaScript 描画が必要なページを扱う場合は、アプリケーション側で Playwright / Puppeteer ローダーを選択してください。

## 1. アセットをビルドする

Worker は `site/docs/dist` の静的アセットも同時に公開します。先に依存関係をインストールして Vocs をビルドしてください。

```bash
# リポジトリ直下
pnpm install --frozen-lockfile
pnpm --filter site build
```

## 2. Worker 名を設定する

`site/wrangler.selfhost.toml.example` をコピーし、自分の Cloudflare アカウント内で一意な `name` を設定します。コピー先は Git の管理対象外です。

```bash
cd site
cp wrangler.selfhost.toml.example wrangler.selfhost.toml
```

`wrangler.selfhost.toml` の `name` は、`<worker-name>.<account-subdomain>.workers.dev` の Worker 名部分になります。

## 3. ローカルで試す

```bash
pnpm worker:dev
```

表示されたローカル URL で、次を確認します。

| URL | 確認内容 |
| --- | --- |
| `/app/` | URL / HTML 入力、AI-ready / Reading モード、コピー・保存機能。 |
| `/api/convert` | JSON API が `markdown` と出典情報を返すこと。 |
| `/` | 静的ドキュメントが配信されること。 |

## 4. Cloudflare へ公開する

ブラウザーで認証できる環境では `wrangler login` を一度実行します。その後、専用設定を指定してデプロイしてください。

```bash
pnpm exec wrangler login
pnpm exec wrangler deploy --config wrangler.selfhost.toml
```

`workers.dev` URL を確認する場合は、デプロイ結果に出力された URL に `/app/` を追加します。

```text
https://<worker-name>.<account-subdomain>.workers.dev/app/
```

## 5. API を確認する

```bash
curl -X POST https://<worker-name>.<account-subdomain>.workers.dev/api/convert \
  -H "Content-Type: application/json" \
  -d '{
    "html": "<article><h1>Hello</h1><p>Prepared for AI.</p></article>",
    "mode": "ai"
  }'
```

本番で限定公開にする場合は、Cloudflare Access などのアクセス制御を先に設定してください。Custom Domain、API の仕様、安全制約、CI でのデプロイ前提は、[Cloudflare Portal ガイド](/portal)にまとめています。
