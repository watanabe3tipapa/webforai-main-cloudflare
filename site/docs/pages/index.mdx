## 役割を明確に分ける

| 場所 | 役割 | 利用者が得るもの |
| --- | --- | --- |
| **GitHub Pages** | プロダクト LP、導入ガイド、SDK / CLI / レシピのドキュメント | webforai が解く課題、使い方、ソースコードへの導線 |
| **Cloudflare Worker ポータル** | URL / HTML を直接変換する Web-UI と API エッジ | LLM-ready Markdown のプレビュー、コピー、`.md` 保存、API 利用 |
| **npm パッケージ** | アプリケーションに組み込める変換ライブラリ | TypeScript で再現可能な HTML → Markdown 処理 |

> **webforai の役割は、ウェブを収集し尽くすことではありません。** 公開された 1 ページを、次の AI 処理に渡せる、見通しのよい Markdown に準備することです。

## Cloudflare ポータルが返すもの

変換ポータルは、YAML frontmatter に変換元 URL、変換モード、変換時刻を付与します。本文は用途に応じて二種類から選べます。**AI-ready** は主コンテンツを中心に画像・表・リンクの装飾を抑え、要約、分類、RAG の小さな入力に適します。**Reading** はリンク、画像、表の情報をできるだけ保持し、人が読み返す Markdown に適します。

ポータルは HTTP(S) の公開ドメインのみを受け付け、ローカルネットワーク、IP アドレス、認証情報付き URL、非標準ポート、過大な入力を拒否します。JavaScript 描画、ログイン、CAPTCHA が必要なページには対応しません。入力するページの利用規約とコンテンツ利用条件は、利用者が確認してください。

[Cloudflare ポータルを開く →](https://webforai-site.kitesurf.workers.dev/app/)

## アプリケーションへの組込み

```ts
import { htmlToMarkdown } from "webforai";

const markdown = htmlToMarkdown(html, {
  baseUrl: "https://example.com/article",
  // デフォルトで本文抽出プリセット takumi を適用
  linkAsText: true,
  tableAsText: true,
  hideImage: true,
});
```

Cloudflare ポータルの API は `POST /api/convert` です。`url` または `html` と、`ai` / `reading` の `mode` を JSON で送信すると、Markdown と変換メタデータを返します。
